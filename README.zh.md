## 🌟 项目简介

**CRT Simulator 2026** 是一款沉浸式的网页端驾驶模拟器，以重庆轨道交通为背景。它利用 Three.js 构建了逼真的 3D 环境，包含程序化地形、动态天气系统以及完整的物理列车模型。

**主要特色：**
- 🗺️ **全网覆盖** – 截至 2026 年 8 月，包含全部 14 条运营线路（1、2、3、4、5、6、9、10、18 号线、环线、国博线、空港线、江跳线、璧铜线）。
- 🏙️ **地标还原** – 李子坝“列车穿楼”、多座长江/嘉陵江大桥、铜元局 45‰ 大坡道等经典场景。
- 🎮 **真实驾驶体验** – ATO（自动驾驶）/ 人工驾驶（ATP 防护）、紧急制动、车门控制、手柄操作。
- 🌦️ **动态环境** – 昼夜循环、晴/雾/雨天气切换、程序化音频引擎（牵引、轮轨、制动、鸣笛）。
- 🔊 **中文语音广播** – 利用 Web Speech API 实现车站到发广播。
- 📊 **值乘评分系统** – 从停站精度、平稳度、准点率、驾驶规范四个维度综合打分，并给出星级评价。

## 🕹️ 操作指南

| 按键               | 功能                           |
|-------------------|----------------------------------|
| `W` / `↑`         | 增加牵引力（加速）              |
| `S` / `↓`         | 增加制动力（减速）              |
| `A` / `D`         | 手柄回零（惰行）                |
| `Space`           | 紧急制动                        |
| `R`               | 缓解紧急制动                    |
| `Q`               | 开启左侧车门                    |
| `E`               | 关闭车门                        |
| `C`               | 切换 ATO / 人工驾驶             |
| `H`（按住）       | 鸣笛                            |
| `L`               | 切换车灯模式                    |
| `V`               | 切换视角（共 6 种）             |
| `1` / `2` / `3`   | 天气：晴 / 雾 / 雨              |
| `T`               | 循环切换当日时间                |
| `P`               | 暂停 / 继续                     |
| `F`               | 全屏模式                        |
| `M`               | 切换左右侧面板显示              |

你也可以直接拖动 HUD 上的 **牵引/制动手柄**，或点击屏幕上的按钮（尤其适合触屏设备）。

## 🛠️ 技术栈

- **3D 引擎** – [Three.js](https://threejs.org/) r160
- **物理系统** – 自定义列车动力学，包含冲击率限制、坡道阻力、ATP 前瞻限速。
- **音频** – WebAudio 合成器（无需外部音频文件）。
- **语音** – Web Speech API（中文普通话）。
- **数据** – 车站坐标、线路参数、历史信息等均整理自公开资料（截至 2026 年 8 月）。
